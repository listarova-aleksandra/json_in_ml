Практический пример

Задача: предсказание удовлетворённости пассажира

Рассмотрим полный демонстрационный кейс использования JSON в ML-системе. Авиакомпания хочет предсказывать, останется ли пассажир доволен полётом, на основе данных о рейсе и оценок сервиса.

Это задача бинарной классификации: модель предсказывает один из двух классов — satisfied (доволен) или neutral_or_dissatisfied (нейтрален или недоволен).

Шаг 1. Входные данные пассажира

Информация о пассажире и его оценки сервиса передаются в формате JSON:

{
    "passenger_id": 7829,
    "gender": "female",
    "age": 27,
    "customer_type": "loyal",
    "travel_type": "business",
    "class": "business",
    "flight_distance": 1200,
    "departure_delay": 0,
    "arrival_delay": 5,
    "ratings": {
        "seat_comfort": 4,
        "food_and_drink": 3,
        "inflight_wifi": 5,
        "inflight_entertainment": 4,
        "online_boarding": 5,
        "leg_room": 4,
        "cleanliness": 5
    }
}

Оценки сервиса — целые числа от 1 до 5. Вложенный объект "ratings" группирует все оценки вместе.

Шаг 2. Описание признаков

Признак Тип Описание
age Числовой Возраст пассажира
flight_distance Числовой Расстояние полёта в милях
customer_type Категориальный Лояльный или новый клиент
class Категориальный Бизнес, эконом или эконом+
seat_comfort Числовой (1–5) Оценка комфорта сиденья
inflight_wifi Числовой (1–5) Оценка WiFi на борту
online_boarding Числовой (1–5) Оценка онлайн-регистрации

Шаг 3. Конфигурация модели

{
    "model": "GradientBoosting",
    "task": "binary_classification",
    "target": "satisfaction",
    "parameters": {
        "n_estimators": 500,
        "learning_rate": 0.05,
        "max_depth": 6
    }
}

Шаг 4. Результат предсказания

Модель обрабатывает данные и возвращает результат:

{
    "passenger_id": 7829,
    "prediction": "satisfied",
    "probabilities": {
        "satisfied": 0.91,
        "neutral_or_dissatisfied": 0.09
    },
    "model_version": "3.2",
    "timestamp": "2026-06-15T14:30:00Z"
}

Модель предсказала, что пассажир будет доволен полётом с вероятностью 91%. Вложенный объект "probabilities" показывает вероятности обоих классов.

Шаг 5. Схема кейса

Данные пассажира (JSON)
↓
Предобработка
↓
GradientBoosting
↓
satisfied (91%)

Что показал этот пример

На каждом шаге JSON играл ключевую роль:

  • Входные данные пассажира переданы в JSON с вложенным объектом оценок
  • Конфигурация модели хранится в JSON-файле
  • Результат предсказания возвращён в JSON с вероятностями обоих классов

Этот сценарий типичен для продакшен-систем: веб-приложение авиакомпании отправляет JSON с данными пассажира на ML API, получает JSON-ответ с предсказанием и показывает результат пользователю.
