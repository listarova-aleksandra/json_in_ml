ML-пайплайн

Что такое ML-пайплайн

ML-пайплайн — это последовательность шагов, через которые проходят данные от сырого вида до готового предсказания. На каждом этапе пайплайна JSON используется для передачи данных, хранения настроек и записи результатов.

Рассмотрим типичный пайплайн на примере задачи классификации: предсказание, уйдёт ли клиент (churn prediction).

Визуализация пайплайна

Схема показывает путь данных через ML-пайплайн — от входного JSON до результата:

Схема пайплайна

1. Входные данные (JSON)
↓
2. Предобработка
↓
3. ML-модель
↓
4. Предсказание
↓
5. Результат (JSON)

Этап 1. Входные данные

Данные о клиенте поступают в формате JSON — например, из веб-формы или API.

{
    "customer_id": 1042,
    "age": 34,
    "tenure_months": 18,
    "monthly_charges": 72.5,
    "contract": "month-to-month",
    "internet_service": "fiber_optic"
}

Этап 2. Предобработка

Перед подачей данных в модель нужно их подготовить: закодировать категориальные признаки, нормализовать числа. Конфигурация предобработки тоже хранится в JSON.

{
    "preprocessing": {
        "numeric_features": ["age", "tenure_months", "monthly_charges"],
        "categorical_features": ["contract", "internet_service"],
        "scaling": "standard",
        "encoding": "one_hot"
    }
}

После предобработки данные преобразуются в числовой вектор, который модель может принять на вход.

Этап 3. Конфигурация модели

Модель загружает свои параметры из JSON-файла конфигурации.

{
    "model_type": "GradientBoosting",
    "version": "3.2",
    "parameters": {
        "n_estimators": 500,
        "learning_rate": 0.05,
        "max_depth": 6
    },
    "trained_on": "2026-03-10",
    "accuracy": 0.94
}

Этап 4. Предсказание

Модель обрабатывает входные данные и формирует предсказание.

Этап 5. Результат

Результат предсказания возвращается в формате JSON — с классом, вероятностями и метаданными.

{
    "customer_id": 1042,
    "prediction": "churn",
    "probability": 0.82,
    "model_version": "3.2",
    "timestamp": "2026-06-15T14:30:00Z"
}

JSON на каждом этапе

Этап Роль JSON Пример содержимого
Входные данные Передача признаков клиента age, tenure, charges
Предобработка Конфигурация трансформаций scaling, encoding
Модель Параметры и гиперпараметры n_estimators, learning_rate
Предсказание Внутренний вычислительный этап —
Результат Ответ с предсказанием prediction, probability

Фан факт

В промышленных ML-системах один пайплайн может включать десятки шагов. Инструменты вроде Apache Airflow и Kubeflow используют JSON и YAML для описания всей цепочки обработки данных.
