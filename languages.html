JSON в языках программирования

Обзор

JSON поддерживается во всех популярных языках программирования. В каждом языке есть встроенные библиотеки или стандартные модули для чтения, создания и обработки JSON. На этой странице мы рассмотрим работу с JSON в четырёх языках: Python, JavaScript, C++ и Java.

Для каждого языка покажем три базовые операции: создание JSON-объекта, преобразование строки JSON в структуру языка (парсинг) и получение значения по ключу.

Python

Python имеет встроенный модуль json, который входит в стандартную библиотеку. Это самый популярный язык в ML, поэтому начинаем с него.

Создание JSON из словаря

import json

data = {
    "model": "RandomForest",
    "accuracy": 0.94,
    "features": ["age", "income"]
}

json_string = json.dumps(data, indent=4)
print(json_string)

Парсинг JSON-строки

import json

json_string = '{"model": "RandomForest", "accuracy": 0.94}'

data = json.loads(json_string)
print(data["model"])
print(data["accuracy"])

Чтение JSON из файла

import json

with open("config.json", "r") as f:
    config = json.load(f)

print(config["model"])

JavaScript

В JavaScript поддержка JSON встроена в язык — методы JSON.parse() и JSON.stringify() доступны без подключения библиотек.

Создание JSON из объекта

const data = {
    model: "RandomForest",
    accuracy: 0.94,
    features: ["age", "income"]
};

const jsonString = JSON.stringify(data, null, 4);
console.log(jsonString);

Парсинг JSON-строки

const jsonString = '{"model": "RandomForest", "accuracy": 0.94}';

const data = JSON.parse(jsonString);
console.log(data.model);
console.log(data.accuracy);

C++

В C++ нет встроенной поддержки JSON, но есть популярная библиотека nlohmann/json (header-only), которая делает работу с JSON простой и удобной.

Создание JSON-объекта

#include <nlohmann/json.hpp>
#include <iostream>

using json = nlohmann::json;

int main() {
    json data;
    data["model"] = "RandomForest";
    data["accuracy"] = 0.94;
    data["features"] = {"age", "income"};

    std::cout << data.dump(4) << std::endl;
    return 0;
}

Парсинг JSON-строки

#include <nlohmann/json.hpp>
#include <iostream>
#include <string>

using json = nlohmann::json;

int main() {
    std::string jsonStr = R"({"model":"RandomForest","accuracy":0.94})";

    json data = json::parse(jsonStr);
    std::cout << data["model"] << std::endl;
    std::cout << data["accuracy"] << std::endl;
    return 0;
}

Java

В Java для работы с JSON используются внешние библиотеки. Одна из самых популярных — org.json. Также часто используются Gson (Google) и Jackson.

Создание JSON-объекта

import org.json.JSONObject;
import org.json.JSONArray;

JSONObject data = new JSONObject();
data.put("model", "RandomForest");
data.put("accuracy", 0.94);

JSONArray features = new JSONArray();
features.put("age");
features.put("income");
data.put("features", features);

System.out.println(data.toString(4));

Парсинг JSON-строки

import org.json.JSONObject;

String jsonStr = "{\"model\":\"RandomForest\",\"accuracy\":0.94}";

JSONObject data = new JSONObject(jsonStr);
System.out.println(data.getString("model"));
System.out.println(data.getDouble("accuracy"));

Сравнение подходов

Язык Библиотека Встроенная Парсинг Сериализация
Python json Да json.loads() json.dumps()
JavaScript Встроена в язык Да JSON.parse() JSON.stringify()
C++ nlohmann/json Нет json::parse() .dump()
Java org.json Нет new JSONObject() .toString()
