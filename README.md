# JSON в Machine Learning (JSON и работа с ним различными языками программирования)

> Ссылка на сайт: https://listarova-aleksandra.github.io/json_in_ml/

Учебный проект о формате JSON и его применении в машинном обучении. Сайт состоит из 10 страниц, объясняющих структуру JSON, его роль в ML-системах и работу с JSON в различных языках программирования.

## Страницы сайта

1. **Главная** — введение в JSON и его роль в ML
2. **Что такое JSON** — основы формата, типы данных, синтаксис
3. **Структура JSON** — объекты, массивы, вложенность, правила
4. **JSON в ML** — применение JSON в машинном обучении
5. **Датасеты** — представление данных для ML в формате JSON
6. **ML API** — JSON как формат обмена данными в API
7. **Языки программирования** — работа с JSON в Python, JavaScript, C++, Java
8. **ML-пайплайн** — JSON на каждом этапе пайплайна
9. **Практический пример** — демо-кейс предсказания удовлетворённости пассажира
10. **Итоги** — резюме и полезные ссылки

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (кастомные стили, медиазапросы, flexbox, grid)
- Cirrus CSS (CSS-фреймворк)
- JavaScript (переключение мобильного меню)

## Запуск

Открыть `index.html` в браузере или запустить через Live Server в VS Code.
