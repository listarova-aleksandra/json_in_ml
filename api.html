JSON в ML API

Что такое ML API

ML API (Application Programming Interface) — это интерфейс, через который приложения могут отправлять данные обученной ML-модели и получать предсказания. В большинстве ML API обмен данными происходит в формате JSON: клиент отправляет JSON-запрос с признаками, а сервер возвращает JSON-ответ с результатом предсказания.

Такой подход позволяет использовать ML-модель из любого языка программирования и любого приложения — достаточно уметь отправлять HTTP-запросы.

Схема работы ML API

Пользователь / Приложение
↓
JSON-запрос
ML API (сервер)
↓
ML-модель
↓
JSON-ответ
Результат предсказания

Пример: классификация клиентов

Представим ML API для предсказания оттока клиентов. Пользователь отправляет данные клиента, а модель возвращает предсказание.

Запрос (Request)

{
    "age": 34,
    "tenure_months": 18,
    "monthly_charges": 72.5,
    "contract": "month-to-month"
}

Ответ (Response)

{
    "prediction": "churn",
    "probability": 0.82,
    "model_version": "2.1"
}

Модель определила, что клиент, вероятнее всего, уйдёт (churn) с вероятностью 82%.

Пример: предсказание цены

ML API может решать задачу регрессии — предсказывать числовое значение.

Запрос

{
    "area_sqm": 65,
    "rooms": 2,
    "floor": 7,
    "district": "central",
    "has_balcony": true
}

Ответ

{
    "predicted_price": 8750000,
    "currency": "RUB",
    "confidence_interval": {
        "lower": 8200000,
        "upper": 9300000
    }
}

Обработка ошибок

Если клиент отправляет некорректные данные, API должен вернуть понятное сообщение об ошибке — тоже в формате JSON.

Запрос с ошибкой

{
    "age": "тридцать",
    "income": 50000
}

Ответ с ошибкой

{
    "error": true,
    "message": "Field 'age' must be a number",
    "code": 400
}

Batch-запросы

Иногда нужно получить предсказания для нескольких объектов сразу. Для этого в JSON передаётся массив:

Запрос

{
    "instances": [
        {"age": 25, "income": 45000},
        {"age": 41, "income": 82000},
        {"age": 29, "income": 55000}
    ]
}

Ответ

{
    "predictions": [
        {"prediction": 0, "probability": 0.23},
        {"prediction": 1, "probability": 0.89},
        {"prediction": 0, "probability": 0.31}
    ]
}

Сравнение форматов в API

Характеристика JSON XML Protobuf
Читаемость Высокая Средняя Низкая (бинарный)
Размер данных Средний Большой Минимальный
Скорость парсинга Быстрая Медленная Очень быстрая
Поддержка языками Все Все Требует генерации кода
Использование в ML API Стандарт Редко gRPC-сервисы

Фан факт

REST API с JSON используют такие ML-платформы, как Google Cloud AI, Amazon SageMaker и Hugging Face Inference API. Все они принимают и возвращают данные в формате JSON.
