Что такое JSON

Определение

JSON (JavaScript Object Notation) — это текстовый формат обмена данными, основанный на синтаксисе объектов JavaScript. Несмотря на название, JSON является языконезависимым форматом и используется практически во всех современных языках программирования.

JSON был предложен Дугласом Крокфордом в начале 2000-х годов как лёгкая альтернатива формату XML. Благодаря простоте и читаемости JSON быстро стал стандартом для обмена данными в веб-приложениях, API и системах машинного обучения.

Основные свойства JSON

  • Текстовый формат, удобный для чтения человеком
  • Лёгкий и компактный по сравнению с XML
  • Языконезависимый — поддерживается в Python, JavaScript, Java, C++ и других языках
  • Поддерживает вложенные структуры данных
  • Используется как стандарт для REST API
  • Легко парсится и генерируется программами

Типы данных в JSON

JSON поддерживает шесть типов данных. Рассмотрим каждый из них с примерами.

Строка (string)

Строка — это последовательность символов в двойных кавычках. Одинарные кавычки в JSON не допускаются.

"name": "RandomForest"

Число (number)

Числа записываются без кавычек. Поддерживаются целые числа и числа с плавающей точкой.

"n_estimators": 100
"learning_rate": 0.01

Логическое значение (boolean)

Может быть только true или false (без кавычек, в нижнем регистре).

"is_trained": true
"use_gpu": false

Null

Специальное значение, обозначающее отсутствие данных. Записывается без кавычек.

"validation_score": null

Массив (array)

Упорядоченный список значений в квадратных скобках. Элементы массива могут быть любого типа.

"features": ["age", "income", "city"]
"scores": [0.85, 0.91, 0.88]

Объект (object)

Набор пар «ключ — значение» в фигурных скобках. Ключ всегда строка, значение — любой тип JSON.

{
    "model": "LogisticRegression",
    "accuracy": 0.92,
    "is_trained": true
}

Сводная таблица типов данных

Тип данных Пример Описание
Строка "hello" Текст в двойных кавычках
Число 42, 3.14 Целое или с плавающей точкой
Boolean true, false Логическое значение
Null null Отсутствие значения
Массив [1, 2, 3] Упорядоченный список значений

Полный пример JSON

Вот пример JSON-документа, который описывает ML-эксперимент. В нём используются все типы данных:

{
    "experiment_name": "classification_v1",
    "model": "RandomForest",
    "n_estimators": 200,
    "accuracy": 0.94,
    "is_deployed": false,
    "failed_reason": null,
    "features": ["age", "income", "region"],
    "metrics": {
        "precision": 0.91,
        "recall": 0.89,
        "f1_score": 0.90
    }
}

В этом примере: experiment_name и model — строки, n_estimators и accuracy — числа, is_deployed — boolean, failed_reason — null, features — массив строк, metrics — вложенный объект с числовыми значениями.

JSON vs XML

JSON часто сравнивают с XML — другим форматом обмена данными. Вот те же данные в обоих форматах:

JSON

{
    "model": "RandomForest",
    "accuracy": 0.94
}

XML

<model>
    <name>RandomForest</name>
    <accuracy>0.94</accuracy>
</model>

JSON компактнее и проще для чтения. Именно поэтому большинство современных API и ML-фреймворков используют JSON вместо XML.
